# Безопасность

## Что защищено в коде

- **Распаковка архивов** (`tray/main.go`, `unix/main.go`): каждый путь из `app.zip` проверяется через `filepath.Clean` и обязан оставаться внутри каталога runtime. Попытка выйти наружу (`../`) прерывает распаковку с ошибкой `illegal file path (Zip Slip attempt)`.
- **Пароль WebDAV**: значения `teledrive`/пустое заменяются случайным паролем (`crypto.randomBytes(16)`), он сохраняется в `.env`. В журнал попадает только предупреждение, без пароля.
- **rclone RC**: вместо `--rc-no-auth` генерируются случайные `--rc-user`/`--rc-pass`; остановка выполняется с теми же учётными данными.
- **Блокировки WebDAV**: записи `LOCK` хранят время создания и удаляются по TTL (1 час), плюс периодическая уборка каждые 10 минут — карта не растёт бесконечно.
- **Секреты не публикуются**: `session.txt`, `.env`, `data/` и `*.exe` в `.gitignore`.

## Правила для дальнейшей разработки

1. Никогда не распаковывать архивы без проверки целевого пути относительно базового каталога.
2. Для любых временных коллекций (карты блокировок, сессии, кэш) предусматривать TTL или ограничение размера.
3. Не использовать пароли по умолчанию (`admin`, `teledrive`, `12345`): генерировать случайные и сохранять локально.
4. Локальные сервисы (rclone rc, control API) должны требовать токен или пароль даже на `127.0.0.1`.
5. Все пути, приходящие извне, нормализовать перед операциями с файловой системой.

## Как сообщить о проблеме

Откройте issue без публикации секретов: не прикладывайте `session.txt`, `.env` и журналы с токенами.
